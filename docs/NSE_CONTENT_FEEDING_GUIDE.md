# دليل تغذية منصة NSE بالمحتوى

كل الطرق التالية تُدخل المحتوى **كمسودات**. لا يظهر شيء للممرضات إلا بعد مراجعة سريرية ولغوية ونشر من الإدارة.

## 1) من الأدوات والإجراءات الموجودة (مجاني، بدون AI)
المصدر: كتالوج المنصة المستورد من النظام القديم (443 أداة ومستهلك، 300 إجراء، خطوات مكافحة العدوى).

| الهدف | المكان في المنصة | ما يحدث |
| --- | --- | --- |
| أسئلة إنجليزية جاهزة للمراجعة | الاستوديو ← الأسئلة ← «توليد أسئلة من الكتالوج بدون ذكاء اصطناعي» | أسئلة مبنية على سطر موثق: الفائدة ← الاسم، الاسم ← الفائدة، قائمة تجهيز الإجراء، ترتيب خطوات مكافحة العدوى. كل سؤال يحفظ السطر كمصدر. |
| هيكل درس عن أداة أو إجراء | الاستوديو ← الدروس ← «ابدأ من أداة أو إجراء أو فكرة» | قالب درس فيه حقائق المصدر وأماكن تحتاج كتابة. لا يُنشر قبل التحرير والمراجعة. |
| تدريب الممرضات مباشرة | الرئيسية: تدريب اليوم، تجهيز التري، أداة اليوم | يستخدم الكتالوج كما هو، بدون مراجعة إضافية لأنه تدريب غير مقيّم. |

مهم: الإجراءات اللي فيها روابط أدوات ناقصة (81 حالة موثقة) مستبعدة تلقائيًا حتى تُصلَح.

## 2) من مصادر رسمية (CDC، WHO، سياسة المركز)
1. نزّلي المصدر الرسمي كملف PDF أو Word أو نص.
2. الاستوديو ← الملفات ← «رفع صورة أو فيديو أو مصدر». المنصة تستخرج النص (بدون OCR للملفات الممسوحة).
3. الاستوديو ← الأسئلة ← «تأليف سؤال بالإنجليزية»: انسخي الاقتباس من المصدر، والمنصة تتحقق أنه موجود حرفيًا في الملف.
4. للدروس: اكتبي الدرس في الاستوديو ← الدروس، واذكري رابط المصدر في نص الدرس.
5. أو اطلبي من Claude في المحادثة كتابة حزمة دروس بالمصادر الرسمية (مثل حزمة الأسنان `content/nse-dental.json`)، وتُجهَّز بزر واحد.

## 3) Claude على اشتراكك الحالي (بدون مفتاح API)
اشتراك Claude (Pro/Max) لا يمكن ربطه بخادم المنصة؛ واجهة API تُحاسَب بشكل منفصل. البديل المجاني على اشتراكك هو «الجسر»:
1. الاستوديو ← تبويب «Claude · مسودات».
2. اختاري التخصص، والمصدر (أدوات أو إجراءات)، وحتى 10 عناصر، ثم «إنشاء الطلب ونسخه».
3. افتحي Claude (claude.ai أو Claude Code) والصقي الطلب. الطلب يقيّد Claude ببيانات الكتالوج فقط ويطلب ردًا بصيغة JSON.
4. انسخي رد Claude كاملًا والصقيه في المربع، ثم «استيراد كمسودات».
5. المنصة ترفض أي سؤال اقتباسه غير موجود حرفيًا في سجل الكتالوج، وأي عنصر من خارج التخصص، والأسئلة المكررة.
6. الدروس المستوردة تدخل مسودة بأربع لغات (اللغة الناقصة تبقى فارغة ومعلّمة)، وتحتاج مراجعة قبل النشر.

## 4) خيار مدفوع اختياري لاحقًا
إذا أردتِ توليدًا داخل المنصة نفسها بضغطة زر، يلزم مفتاح API مدفوع حسب الاستخدام. أرخص نموذج Claude حاليًا (Haiku 5.5) تكلفته تقريبًا 0.10 دولار لكل مليون رمز إدخال و0.50 دولار لكل مليون رمز إخراج، أي أن مئات الأسئلة تكلف سنتات. هذا اختياري، ولا يلزم لأي ميزة أعلاه.
